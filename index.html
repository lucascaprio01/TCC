Parâmetros de Forma e Dimensão Orbital (Plano Orbital)

O Semieixo Maior (\(a\)) e a Energia Orbital

DicaQuestão Problema

Se dois satélites orbitam a Terra em altitudes diferentes, qual deles necessita de maior velocidade e qual possui o maior período orbital (tempo para dar uma volta completa)? Como o tamanho da órbita se relaciona com a energia mecânica do satélite?

O semieixo maior (\(a\)) representa a metade do diâmetro principal de uma órbita elíptica, definindo a escala espacial e a dimensão geométrica da trajetória. De acordo com o Problema dos Dois Corpos, a energia mecânica específica total (\(\varepsilon\)) de uma órbita depende exclusivamente do semieixo maior:

\[\varepsilon = \frac{v^2}{2} - \frac{\mu}{r} = -\frac{\mu}{2a}\] onde \(\mu = GM\) é o parâmetro gravitacional padrão da Terra (\(\approx 3,986 \times 10^{14}\text{ m}^3/\text{s}^2\)) e \(r\) é a distância geocêntrica instantânea.

Dessa relação deriva-se a Equação da Vis-Viva, que fornece o módulo da velocidade orbital instantânea \(v\) em qualquer ponto \(r\): \[v^2 = \mu \left( \frac{2}{r} - \frac{1}{a} \right)\]Pela Terceira Lei de Kepler (Lei dos Períodos), o quadrado do período orbital (\(T^2\)) é diretamente proporcional ao cubo do semieixo maior (\(a^3\)): \[T^2 = \frac{4\pi^2}{\mu} a^3\]

Na simulação a seguir, utilize o controle deslizante Semieixo maior (a). Mantenha a excentricidade fixa (\(e = 0,3\)). Observe a variação no tamanho da elipse.

grade_quadrada = function(xdom, ydom, xlabel, ylabel) {
  const margem = {top: 25, right: 20, bottom: 45, left: 50};
  const larguraMax = 700;   // largura total máxima do gráfico (px)
  const pxMax = 26;         // tamanho máximo de 1 unidade (px)

  const dx = xdom[1] - xdom[0];
  const dy = ydom[1] - ydom[0];

  // Pixels por unidade: o MESMO valor é usado nos dois eixos
  const px = Math.min(pxMax, (larguraMax - margem.left - margem.right) / dx);

  // Marcas (e linhas de grade) a cada 1 unidade
  const marcas = (d) => Array.from({length: Math.floor(d[1] - d[0]) + 1}, (_, k) => d[0] + k);

  return {
    width: dx * px + margem.left + margem.right,
    height: dy * px + margem.top + margem.bottom,
    marginTop: margem.top,
    marginRight: margem.right,
    marginBottom: margem.bottom,
    marginLeft: margem.left,
    grid: true,
    x: {domain: xdom, ticks: marcas(xdom), label: xlabel},
    y: {domain: ydom, ticks: marcas(ydom), label: ylabel}
  };
}

A Excentricidade (\(e\)) e a Geometria das Cônicas

DicaQuestão Problema

A órbita da Terra ao redor do Sol é uma elipse muito “achatada” ou quase um círculo? A variação da distância entre a Terra e o Sol ao longo do ano é a causa primária das estações do ano?

A excentricidade (\(e\)) é o parâmetro adimensional que mede o “grau de achatamento” ou o desvio de uma seção cônica em relação a uma circunferência perfeita:

  • \(e = 0\): Órbita circular perfeita.

  • \(0 < e < 1\): Órbita elíptica.

  • \(e = 1\): Trajetória parabólica.

  • \(e > 1\): Trajetória hiperbólica.

A equação da cônica em coordenadas polares centradas no foco é dada por:

\[r(\nu) = \frac{a(1 - e^2)}{1 + e \cos \nu},\]

onde \(\nu\) é a anomalia verdadeira. A distância de máxima aproximação (perigeu, \(r_p\)) e de máximo afastamento (apogeu, \(r_a\)) são expressas por:

\[r_p = a(1 - e) \quad \text{e} \quad r_a = a(1 + e).\]

Pela Conservação do Momento Angular Específico (\(\vec{h} = \vec{r} \times \vec{v} = \text{constante}\)), a velocidade orbital no perigeu (\(v_p\)) é maior que no apogeu (\(v_a\)) para trajetórias elípticas:

\[\frac{v_p}{v_a} = \frac{1 + e}{1 - e}\]

Superação de Concepção Alternativa: Ilustrações em livros didáticos costumam representar a órbita da Terra com excentricidade excessivamente acentuada, induzindo a ideia incorreta de que as estações do ano seriam causadas pela aproximação ou afastamento do Sol. Na realidade, a excentricidade terrestre é de apenas \(e \approx 0,017\), tornando a órbita visualmente indistinguível de um círculo.

A Inclinação Orbital (\(i\)) e o Plano Equatorial

DicaQuestão Problema

O que significa dizer que um satélite possui uma “órbita polar” ou uma “órbita equatorial”? Como o ângulo do plano orbital afeta as regiões da Terra sobre as quais o satélite consegue passar?

A inclinação (\(i\)) é o ângulo medido entre o plano orbital do satélite e o plano equatorial de referência da Terra (\(0^\circ \le i \le 180^\circ\)):

  • Órbita Equatorial (\(i = 0^\circ\) ou \(i = 180^\circ\)): O plano da órbita coincide com o plano equatorial terrestre.

  • Órbita Polar (\(i = 90^\circ\)): O plano orbital passa diretamente sobre os polos geográficos.

  • Órbita Prógrada (\(0^\circ \le i < 90^\circ\)): O satélite orbita no mesmo sentido de rotação da Terra (Oeste para Leste).

  • Órbita Retrógrada (\(90^\circ < i \le 180^\circ\)): O satélite orbita em sentido oposto à rotação terrestre.

A inclinação determina as latitudes máximas ao Norte e ao Sul que a projeção da órbita no solo (ground track) consegue alcançar.

Na simulação a seguir, altere a inclinação \(i\) de \(0^\circ\) a \(180^\circ\) na cena 3D. Observe o basculamento do plano orbital em relação ao equador terrestre.

A Ascensão Reta do Nó Ascendente (\(\Omega\))

A Ascensão Reta do Nó Ascendente (\(\Omega\) ou RAAN) é o ângulo medido no plano equatorial entre a direção de referência inercial, o Ponto Vernal (\(\gamma\)) (equinócio de primavera), e o Nó Ascendente. O nó ascendente é o ponto onde o satélite cruza o plano equatorial vindo do hemisfério Sul em direção ao hemisfério Norte (\(0^\circ \le \Omega < 360^\circ\)).

A alteração de \(\Omega\) promove uma rotação do plano orbital ao redor do eixo polar terrestre (eixo Z inercial).

Na simulação a seguir, altere o parâmetro \(\Omega\) de \(0^\circ\) a \(360^\circ\) mantendo \(i = 45^\circ\). Observe como a linha dos nós gira no plano equatorial sem alterar a inclinação da órbita.

O Argumento do Perigeu (\(\omega\))

O Argumento do Perigeu (\(\omega\)) é o ângulo medido dentro do plano orbital entre o nó ascendente e a direção do perigeu (ponto de máxima aproximação) (\(0^\circ \le \omega < 360^\circ\)).

Enquanto \(\Omega\) orienta o plano no espaço inercial, \(\omega\) orienta a própria elipse dentro do seu plano orbital.

A Anomalia Verdadeira (\(\nu\)) e o Movimento em Órbita

A Anomalia Verdadeira (\(\nu\) ou \(f\)) é o ângulo polar instantâneo medido no plano orbital a partir da direção do perigeu até a posição atual do satélite (\(0^\circ \le \nu < 360^\circ\)):

  • \(\nu = 0^\circ\): Satélite no perigeu (máxima velocidade, menor distância).

  • \(\nu = 180^\circ\): Satélite no apogeu (mínima velocidade, maior distância).

A determinação da posição temporal exige a resolução da Equação de Kepler via Anomalia Média (\(M\)) e Anomalia Excêntrica (\(u\)):

\[M = u - e \sin u\]

Regimes de Órbitas Terrestres e Aplicações Aeroespaciais

Análise Comparativa – LEO, MEO, GEO e Polar

Na astrodinâmica e na engenharia espacial, as órbitas terrestres são classificadas em quatro regimes principais com base na altitude, inclinação e período:

1. Órbita Terrestre Baixa (LEO - Low Earth Orbit):

  • Altitude: \(\sim 160\text{ km}\) a \(2.000\text{ km}\).

  • Velocidade e Período: Alta velocidade (\(\sim 7,8\text{ km/s}\)) e período curto (\(\sim 90\text{ minutos}\)).

  • Aplicações: Estação Espacial Internacional (ISS), satélites de observação e fotografia.

2. Órbita Terrestre Média (MEO - Medium Earth Orbit):

  • Altitude: \(\sim 2.000\text{ km}\) a \(35.786\text{ km}\) (típica de \(\sim 20.200\text{ km}\)).

  • Período: Típico de \(12\text{ horas}\) (semissíncrona).

  • Aplicações: Constelações de navegação por satélite (GPS, GLONASS, Galileo).

3. Órbita Geoestacionária (GEO - Geostationary Earth Orbit):

  • Altitude e Geometria: Circular equatorial (\(i = 0^\circ\), \(e = 0\)) a \(a \approx 42.164\text{ km}\) (\(z \approx 35.786\text{ km}\)).

  • Período: Exatamente \(24\text{ horas siderais}\) (\(86.164\text{ s}\)).

  • Propriedade: Move-se com a mesma velocidade angular da Terra, permanecendo fixa em relação a um ponto no equador.

  • Aplicações: Telecomunicações, transmissão de TV e meteorologia contínua.

4. Órbita Polar:

  • Inclinação: \(i \approx 90^\circ\).

  • Aplicações: Como a Terra gira por baixo do plano orbital, o satélite varre e mapeia 100% da superfície ao longo de sucessivas voltas.

Na simulação a seguir, ative a visualização comparativa tridimensional. Alterne entre os regimes LEO, MEO, GEO e Polar e observe as diferenças de escala, altitude e velocidade de translação em relação ao globo terrestre.

  const f_acel = (st) => {
    let r = [st[0], st[1], st[2]];
    let v = [st[3], st[4], st[5]];
    let mag = f_mag(r);
    if (mag === 0) throw new Error("Colisão!");
    
    let fat = -mu / Math.pow(mag, 3);
    let a = f_mul(r, fat);
    return [...v, ...a];
  };

  const step_rk = (y_in, h_in) => {
    let k1 = f_mul(f_acel(y_in), h_in);
    let k2 = f_mul(f_acel(v_sum(y_in, f_mul(k1, 1/4))), h_in);
    let k3 = f_mul(f_acel(v_sum(y_in, f_mul(k1, 3/32), f_mul(k2, 9/32))), h_in);
    let k4 = f_mul(f_acel(v_sum(y_in, f_mul(k1, 1932/2197), f_mul(k2, -7200/2197), f_mul(k3, 7296/2197))), h_in);
    let k5 = f_mul(f_acel(v_sum(y_in, f_mul(k1, 439/216), f_mul(k2, -8), f_mul(k3, 3680/513), f_mul(k4, -845/4104))), h_in);
    let k6 = f_mul(f_acel(v_sum(y_in, f_mul(k1, -8/27), f_mul(k2, 2), f_mul(k3, -3544/2565), f_mul(k4, 1859/4104), f_mul(k5, -11/40))), h_in);

    let w_out = v_sum(y_in, f_mul(k1, 25/216), f_mul(k3, 1408/2565), f_mul(k4, 2197/4104), f_mul(k5, -1/5));
    let q_out = v_sum(y_in, f_mul(k1, 16/135), f_mul(k3, 6656/12825), f_mul(k4, 28561/56430), f_mul(k5, -9/50), f_mul(k6, 2/55));
    
    return { w_out, q_out };
  };

  let tol = 1e-9;
  let state = [r0_x, r0_y, r0_z, v0_x, v0_y, v0_z];
  let t_curr = 0;
  let h_curr = 10.0;
  let max_it = 10000;
  let it = 0;
  
  let res = [];
  
  while (t_curr < v_tmax && it < max_it) {
    let { w_out, q_out } = step_rk(state, h_curr);
    let diff = f_mag(f_sub(w_out, q_out));
    let scale = Math.max(f_mag(state), 1e-8);
    let err = diff / scale;
    
    if (err > tol) {
      h_curr = 0.9 * h_curr * Math.pow(tol / err, 0.2);
      continue;
    }
    
    state = q_out;
    t_curr += h_curr;
    it++;
    
    if (err < 0.1 * tol) h_curr *= 2.0;
    if (t_curr + h_curr > v_tmax) h_curr = v_tmax - t_curr;
    
    res.push({
      t: t_curr,
      x: state[0], y: state[1], z: state[2]
    });
  }
  
  return res;
}

# Parâmetros de Forma e Dimensão Orbital (Plano Orbital)

## O Semieixo Maior ($a$) e a Energia Orbital

::: {.callout-tip title="Questão Problema"}
Se dois satélites orbitam a Terra em altitudes diferentes, qual deles necessita de maior velocidade e qual possui o maior período orbital (tempo para dar uma volta completa)? Como o tamanho da órbita se relaciona com a energia mecânica do satélite?
:::

O semieixo maior ($a$) representa a metade do diâmetro principal de uma órbita elíptica, definindo a escala espacial e a dimensão geométrica da trajetória. De acordo com o Problema dos Dois Corpos, a energia mecânica específica total ($\varepsilon$) de uma órbita depende exclusivamente do semieixo maior: 

$$\varepsilon = \frac{v^2}{2} - \frac{\mu}{r} = -\frac{\mu}{2a}$$ onde $\mu = GM$ é o parâmetro gravitacional padrão da Terra ($\approx 3,986 \times 10^{14}\text{ m}^3/\text{s}^2$) e $r$ é a distância geocêntrica instantânea.

Dessa relação deriva-se a Equação da Vis-Viva, que fornece o módulo da velocidade orbital instantânea $v$ em qualquer ponto $r$: $$v^2 = \mu \left( \frac{2}{r} - \frac{1}{a} \right)$$Pela Terceira Lei de Kepler (Lei dos Períodos), o quadrado do período orbital ($T^2$) é diretamente proporcional ao cubo do semieixo maior ($a^3$): $$T^2 = \frac{4\pi^2}{\mu} a^3$$

Na simulação a seguir, utilize o controle deslizante Semieixo maior (a). Mantenha a excentricidade fixa ($e = 0,3$). Observe a variação no tamanho da elipse.

## A Excentricidade ($e$) e a Geometria das Cônicas
::: {.callout-tip title="Questão Problema"}
A órbita da Terra ao redor do Sol é uma elipse muito "achatada" ou quase um círculo? A variação da distância entre a Terra e o Sol ao longo do ano é a causa primária das estações do ano?
:::

A excentricidade ($e$) é o parâmetro adimensional que mede o "grau de achatamento" ou o desvio de uma seção cônica em relação a uma circunferência perfeita:

- $e = 0$: Órbita circular perfeita.

- $0 < e < 1$: Órbita elíptica.

- $e = 1$: Trajetória parabólica.

- $e > 1$: Trajetória hiperbólica.

A equação da cônica em coordenadas polares centradas no foco é dada por: 

$$r(\nu) = \frac{a(1 - e^2)}{1 + e \cos \nu},$$ 

onde $\nu$ é a anomalia verdadeira. A distância de máxima aproximação (perigeu, $r_p$) e de máximo afastamento (apogeu, $r_a$) são expressas por:

 $$r_p = a(1 - e) \quad \text{e} \quad r_a = a(1 + e).$$
 
 Pela Conservação do Momento Angular Específico ($\vec{h} = \vec{r} \times \vec{v} = \text{constante}$), a velocidade orbital no perigeu ($v_p$) é maior que no apogeu ($v_a$) para trajetórias elípticas:
 
 $$\frac{v_p}{v_a} = \frac{1 + e}{1 - e}$$
 
Superação de Concepção Alternativa: Ilustrações em livros didáticos costumam representar a órbita da Terra com excentricidade excessivamente acentuada, induzindo a ideia incorreta de que as estações do ano seriam causadas pela aproximação ou afastamento do Sol. Na realidade, a excentricidade terrestre é de apenas $e \approx 0,017$, tornando a órbita visualmente indistinguível de um círculo.

# Orientação Espacial Tridimensional (Ângulos de Euler)

## A Inclinação Orbital ($i$) e o Plano Equatorial
::: {.callout-tip title="Questão Problema"}
O que significa dizer que um satélite possui uma "órbita polar" ou uma "órbita equatorial"? Como o ângulo do plano orbital afeta as regiões da Terra sobre as quais o satélite consegue passar?
:::

A inclinação ($i$) é o ângulo medido entre o plano orbital do satélite e o plano equatorial de referência da Terra ($0^\circ \le i \le 180^\circ$):

- Órbita Equatorial ($i = 0^\circ$ ou $i = 180^\circ$): O plano da órbita coincide com o plano equatorial terrestre.

- Órbita Polar ($i = 90^\circ$): O plano orbital passa diretamente sobre os polos geográficos.

- Órbita Prógrada ($0^\circ \le i < 90^\circ$): O satélite orbita no mesmo sentido de rotação da Terra (Oeste para Leste).

- Órbita Retrógrada ($90^\circ < i \le 180^\circ$): O satélite orbita em sentido oposto à rotação terrestre.

A inclinação determina as latitudes máximas ao Norte e ao Sul que a projeção da órbita no solo (ground track) consegue alcançar.

## A Ascensão Reta do Nó Ascendente ($\Omega$)
A Ascensão Reta do Nó Ascendente ($\Omega$ ou RAAN) é o ângulo medido no plano equatorial entre a direção de referência inercial, o Ponto Vernal ($\gamma$) (equinócio de primavera), e o Nó Ascendente. O nó ascendente é o ponto onde o satélite cruza o plano equatorial vindo do hemisfério Sul em direção ao hemisfério Norte ($0^\circ \le \Omega < 360^\circ$).

A alteração de $\Omega$ promove uma rotação do plano orbital ao redor do eixo polar terrestre (eixo Z inercial).

Na simulação a seguir, altere o parâmetro $\Omega$ de $0^\circ$ a $360^\circ$ mantendo $i = 45^\circ$. Observe como a linha dos nós gira no plano equatorial sem alterar a inclinação da órbita.

## O Argumento do Perigeu ($\omega$)
O Argumento do Perigeu ($\omega$) é o ângulo medido dentro do plano orbital entre o nó ascendente e a direção do perigeu (ponto de máxima aproximação) ($0^\circ \le \omega < 360^\circ$).

# Dinâmica Temporal e Posição Instantânea

## A Anomalia Verdadeira ($\nu$) e o Movimento em Órbita
A Anomalia Verdadeira ($\nu$ ou $f$) é o ângulo polar instantâneo medido no plano orbital a partir da direção do perigeu até a posição atual do satélite ($0^\circ \le \nu < 360^\circ$):

- $\nu = 0^\circ$: Satélite no perigeu (máxima velocidade, menor distância).

- $\nu = 180^\circ$: Satélite no apogeu (mínima velocidade, maior distância).

A determinação da posição temporal exige a resolução da Equação de Kepler via Anomalia Média ($M$) e Anomalia Excêntrica ($u$):

 $$M = u - e \sin u$$

Na simulação a seguir, mova o controle deslizante de $\nu$ de $0^\circ$ a $360^\circ$ e observe o deslocamento do satélite e do vetor posição $\vec{r}$ ao longo da órbita.

# Regimes de Órbitas Terrestres e Aplicações Aeroespaciais

## Análise Comparativa – LEO, MEO, GEO e Polar
Na astrodinâmica e na engenharia espacial, as órbitas terrestres são classificadas em quatro regimes principais com base na altitude, inclinação e período:

**1. Órbita Terrestre Baixa (LEO - Low Earth Orbit):**

  - Altitude: $\sim 160\text{ km}$ a $2.000\text{ km}$.

  - Velocidade e Período: Alta velocidade ($\sim 7,8\text{ km/s}$) e período curto ($\sim 90\text{ minutos}$).

  - Aplicações: Estação Espacial Internacional (ISS), satélites de observação e fotografia.
  
**2. Órbita Terrestre Média (MEO - Medium Earth Orbit):**

  - Altitude: $\sim 2.000\text{ km}$ a $35.786\text{ km}$ (típica de $\sim 20.200\text{ km}$).
  
  - Período: Típico de $12\text{ horas}$ (semissíncrona).
  
  - Aplicações: Constelações de navegação por satélite (GPS, GLONASS, Galileo).
  
**3. Órbita Geoestacionária (GEO - Geostationary Earth Orbit):**

  - Altitude e Geometria: Circular equatorial ($i = 0^\circ$, $e = 0$) a $a \approx 42.164\text{ km}$ ($z \approx 35.786\text{ km}$).
  
  - Período: Exatamente $24\text{ horas siderais}$ ($86.164\text{ s}$).
  
  - Propriedade: Move-se com a mesma velocidade angular da Terra, permanecendo fixa em relação a um ponto no equador.
  
  - Aplicações: Telecomunicações, transmissão de TV e meteorologia contínua.
  
**4. Órbita Polar:**

  - Inclinação: $i \approx 90^\circ$.

  - Aplicações: Como a Terra gira por baixo do plano orbital, o satélite varre e mapeia 100% da superfície ao longo de sucessivas voltas.

dados_simulacao = {
  // Se o botão de reset for clicado, encerra a função e retorna vazio
  if (acao_botoes === "reset") {
    return [];
  }

  // Lemos os valores usando '.value' da raiz do DOM para evitar reatividade automática ao digitar
  let v_tmax = viewof t_max.value;
  let v_inc = viewof inc_graus.value;
  let v_rx = viewof rx.value;
  let v_ry = viewof ry.value;
  let v_rz = viewof rz.value;
  let v_vx = viewof vx.value;
  let v_vy = viewof vy.value;
  let v_vz = viewof vz.value;

  let inc_rad = v_inc * Math.PI / 180;
  
  let r0_x = v_rx;
  let r0_y = (v_ry * Math.cos(inc_rad)) - (v_rz * Math.sin(inc_rad));
  let r0_z = (v_ry * Math.sin(inc_rad)) + (v_rz * Math.cos(inc_rad));

  let v0_x = v_vx;
  let v0_y = (v_vy * Math.cos(inc_rad)) - (v_vz * Math.sin(inc_rad));
  let v0_z = (v_vy * Math.sin(inc_rad)) + (v_vz * Math.cos(inc_rad));

  const mu = 398600.0;

  const f_add = (a, b) => a.map((v, i) => v + b[i]);
  const f_sub = (a, b) => a.map((v, i) => v - b[i]);
  const f_mul = (a, s) => a.map(v => v * s);
  const f_mag = (a) => Math.sqrt(a.reduce((acc, v) => acc + v * v, 0));

  const v_sum = (...vecs) => {
    let res = [...vecs[0]];
    for(let i = 1; i < vecs.length; i++){
      for(let j = 0; j < res.length; j++){
        res[j] += vecs[i][j];
      }
    }
    return res;
  };

  const f_acel = (st) => {
    let r = [st[0], st[1], st[2]];
    let v = [st[3], st[4], st[5]];
    let mag = f_mag(r);
    if (mag === 0) throw new Error("Colisão!");
    
    let fat = -mu / Math.pow(mag, 3);
    let a = f_mul(r, fat);
    return [...v, ...a];
  };

  const step_rk = (y_in, h_in) => {
    let k1 = f_mul(f_acel(y_in), h_in);
    let k2 = f_mul(f_acel(v_sum(y_in, f_mul(k1, 1/4))), h_in);
    let k3 = f_mul(f_acel(v_sum(y_in, f_mul(k1, 3/32), f_mul(k2, 9/32))), h_in);
    let k4 = f_mul(f_acel(v_sum(y_in, f_mul(k1, 1932/2197), f_mul(k2, -7200/2197), f_mul(k3, 7296/2197))), h_in);
    let k5 = f_mul(f_acel(v_sum(y_in, f_mul(k1, 439/216), f_mul(k2, -8), f_mul(k3, 3680/513), f_mul(k4, -845/4104))), h_in);
    let k6 = f_mul(f_acel(v_sum(y_in, f_mul(k1, -8/27), f_mul(k2, 2), f_mul(k3, -3544/2565), f_mul(k4, 1859/4104), f_mul(k5, -11/40))), h_in);

    let w_out = v_sum(y_in, f_mul(k1, 25/216), f_mul(k3, 1408/2565), f_mul(k4, 2197/4104), f_mul(k5, -1/5));
    let q_out = v_sum(y_in, f_mul(k1, 16/135), f_mul(k3, 6656/12825), f_mul(k4, 28561/56430), f_mul(k5, -9/50), f_mul(k6, 2/55));
    
    return { w_out, q_out };
  };

  let tol = 1e-9;
  let state = [r0_x, r0_y, r0_z, v0_x, v0_y, v0_z];
  let t_curr = 0;
  let h_curr = 10.0;
  let max_it = 10000;
  let it = 0;
  
  let res = [];
  
  while (t_curr < v_tmax && it < max_it) {
    let { w_out, q_out } = step_rk(state, h_curr);
    let diff = f_mag(f_sub(w_out, q_out));
    let scale = Math.max(f_mag(state), 1e-8);
    let err = diff / scale;
    
    if (err > tol) {
      h_curr = 0.9 * h_curr * Math.pow(tol / err, 0.2);
      continue;
    }
    
    state = q_out;
    t_curr += h_curr;
    it++;
    
    if (err < 0.1 * tol) h_curr *= 2.0;
    if (t_curr + h_curr > v_tmax) h_curr = v_tmax - t_curr;
    
    res.push({
      t: t_curr,
      x: state[0], y: state[1], z: state[2]
    });
  }
  
  return res;
}
